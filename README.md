# Lattice

**Open knowledge, beautifully organized.**

Lattice is an open-source, self-hosted wiki for people and teams. Organize knowledge in workspaces, write rich pages, and keep ownership of your data.

## Development status

Lattice is under active initial development. Implementation, installation instructions, and verified feature status will be added as each part lands.

## Direction

- TypeScript and Next.js for the application
- PostgreSQL for persistent data
- TipTap for a rich, keyboard-friendly editor
- Secure sessions, workspace permissions, revision history, and local attachment storage
- Docker for self-hosting
